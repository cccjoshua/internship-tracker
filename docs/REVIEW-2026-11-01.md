# Redesign review — Phase 2 (2026-11-01)

Method: Assessment A (design critique, 7 pages, light + dark, plus Apple HIG review) ran as an isolated sub-agent. Assessment B ran afterwards in the main session: `impeccable detect` on the source (exit 2, 7 findings), axe-core 4.10 (WCAG 2.0/2.1/2.2 A+AA) on 6 pages, and DOM/network checks. Not run: `npx impeccable detect http://127.0.0.1:8765` (URL scan needs Chrome on the Mac; run it locally). Horizontal-overflow checks were void because the browser pane was hidden.

Nielsen score 25/40 (acceptable). Weakest: Aesthetic & minimalist (1), Consistency (2), Recognition over recall (2), Error recovery (2). Cognitive load: high (5 of 8 checks fail).
axe-core: 0 violations on Dashboard, Applications, New listings, Documents, Settings; Profile: `target-size` ×4 (skill-level inputs).
Detector: phone tab-bar labels at 10.5px (×6); repeating-gradient stripes on unknown fit bars (`apple.css:338`, intentional "no data" pattern → keep but restyle).
"Owner" = issue the owner reported in the redesign plan.

## P0 — breaks the core job or accessibility
1. **Filled-button overload + fake button.** New listings: 50 filled primaries in the DOM (~12 visible); Dashboard 7; List 4; board cards have full-width filled Apply/Prepare. `.act.now` "Apply now" is a non-interactive `<span>` styled as a filled button (`base.css:378`). → One filled primary per view; row actions plain/tinted; "Apply now" becomes text or is dropped. (Owner; A; HIG buttons)
2. **Board cards have no visible keyboard focus.** `.card{box-shadow}` (`apple.css:214`) overrides `:focus-visible` (`apple.css:72`), so the documented Shift+arrow flow is blind. WCAG 2.4.7. (A)
3. **Search palette.** Saturated full-accent active row (`apple.css:269`); flat empty state of 15 commands each labelled "Command"; ranking puts a Rejected application first for "nvidia"; "No matches" with no recovery; no match highlighting; off-spec size. → Phase 3 rebuild. (Owner; A)

## P1 — main visual-system fixes
4. **Sidebar selection.** Owner sees a blue outline ring on the active item; source uses grey `--fill` (`apple.css:86`), which undid base.css's tint. → `--selection` tint + 590 weight, no ring on mouse navigation; counts as plain secondary text. (Owner; A)
5. **Badge overload and orange/green noise.** Saved, Analyzed, Tailored resume, Letter, "Tailor first", Instant, Next refresh, Within 5 min. Orange is used for non-warnings, so real overdue signals get ignored. → ≤1 actionable badge per row; info states become icons/peek; timing hints move to the status line. (Owner; A)
6. **Score color carries no information.** Rings nearly all green (`band()` `app.js:361`); fit bars green/orange/red; weekly goal line in `--warn`. → Neutral tabular score, accent only for the top band, goal line in secondary label. (Owner; A)
7. **Dense "·" metadata.** Listing rows carry up to 9 facts and wrap to 3 lines. → company · role + one decisive fact; the rest in the peek. (Owner; A)
8. **Settings layout.** ~400px numeric fields holding "10", "2", "75". → System Settings inset grouped rows with compact fields/steppers (copy the existing Weights rows). (Owner; A)
9. **Back crumb on top-level pages.** Documents, Profile, Settings show "← Back to New listings", even when you didn't come from there (`backCrumb()` `app.js:405–412`). (Owner; A)
10. **Sidebar footer.** Save state truncated ("Saved to data/tracker.js…"), no time; stray floating tooltip bottom-right. → "Saved · 4:52 PM", path in tooltip; remove the floating tooltip. (Owner; A)
11. **Tokens off the system.** Accent `#0064D2` in both themes (spec `#007AFF` / `#0A84FF`); dark background `#000` with `#1C1C1E` panels, sidebar and content read as one slab. (A)

## P2 — page-level refinements
12. **Dashboard.** "Needs attention" tile duplicates the panel (3- vs 7-day windows); hero KPI cards; pencil icons on stat cards; empty pipeline bars and large empty areas; "7 picks" link vs 6 queue rows. (Owner; A)
13. **Applications board.** Empty columns take full width with "Drop a card here"; Closed column clipped; "No deadline" noise; Assessment indigo vs Interviewing purple (spec: one indigo). (Owner; A)
14. **Applications list.** Black filled stage-filter pill (`apple.css:201`); two tables with different column sets; every status pop-up is the same blue capsule. (A)
15. **New listings.** Red/orange "Add if true: A/B testing" is confusing → neutral wording, e.g. "Could add if true: A/B testing". 9 controls above the first row; Today's queue duplicated from the Dashboard above the fold. (Owner; A)
16. **Documents.** Base-resume cards truncate text; search sits in the body, and `/` does nothing here (`app.js:1653`); black filter pill; column offsets between groups. (Owner; A)
17. **Profile.** "100% complete" next to "10 points need confirming"; autosave plus "Instant" badges vs Save buttons elsewhere; skill-level inputs fail axe `target-size`. (A; axe)
18. **Settings.** One very long page (Claude/model block dominates) → panes per index item or collapsed groups; Remove key / Reset scoring look like ordinary buttons → plain red + confirm. (A)
19. **Type, radius, depth.** 20+ font sizes incl. 12.5/11.5/13.5; body 14 → 13; radii 1–28 + 999 → 6/10/14; shadow on every card → hairline grouped lists. (A; DESIGN.md)
20. **macOS shortcuts.** Add ⌘, (Settings), ⌘N (Add application), ⌘F (find on page) alongside all existing shortcuts; show shortcuts in palette rows. (A; HIG keyboards)
